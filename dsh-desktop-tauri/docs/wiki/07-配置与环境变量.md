# 07 · 配置与环境变量

## 1. 环境变量全表（Rust 侧，grep 全量核对）

### 启动与挂载

| 变量 | 作用 |
|---|---|
| `DSH_REPO_ROOT` | monorepo/harness 检出根。运行期 `default_checkout` 第一来源；`prepare:runtime` 重新生成闭包的必要输入 |
| `DSH_CHECKOUT` | 直接指定检出；指到但没有 `apps\cli\lib\bin.js` 是**硬错误**（不静默降级） |
| `DSH_TAURI_CMD` | 完全自定义 Host 启动程序（梯级第 1 级） |
| `DSH_TAURI_ARGS` | 上面的参数，**JSON 字符串数组** |
| `DSH_TAURI_CWD` | Host 工作目录（会话按 workspace 分桶，用它指定要延续哪桶；默认 `USERPROFILE`） |
| `DSH_TAURI_NODE` | 指定 node.exe（覆盖 bundled 与 PATH） |
| `DSH_TAURI_PORT` | 换固定端口（默认 3090；换就换得稳定，绝不自动漂移） |
| `DSH_TAURI_PROFILE` | web profile 参数（默认见 `web_args`） |
| `DSH_TAURI_HOME` | 注入子进程 `DSH_HOME`：状态根（会话/日志/任务板锁） |
| `DSH_TAURI_TAKEOVER` | **默认开**：起 Host 前先“退休”本登录会话里占着任务板/状态根的其它 DSH Host（last-writer-wins，让桌面壳与终端会话无需第二状态根）。设 `0` 恢复不侵入行为 |

### 内核更新（harness_update）

| 变量 | 作用 |
|---|---|
| `DSH_REPO_URL` | 引导/缺 origin 时的 remote（fork/中转） |
| `DSH_REPO_REF` | 同步目标（tag/分支/SHA），覆盖“最新 dsh-v* tag”策略 |
| `DSH_GIT_MIRROR` | 镜像列表，分号分隔；`{url}` 占位式或前缀式；排在三个公共 gh 代理之前 |
| `DSH_LOCAL_PATCHES_DIR` | 本地补丁规范副本目录（含 `restore-local-patches.mjs`）；显式指定则**指错就失败**，不回退 |
| `DSH_SKIP_LOCAL_PATCHES` | 非空 = 跳过全部补丁阶段（无补丁部署）；刻意留痕 |

### 更新与诊断

| 变量 | 作用 |
|---|---|
| `DSH_TAURI_UPDATE_ENDPOINT` | 覆盖壳更新 feed（逗号列表逐个试）；仅测试用，release 保持 https 官方 |
| `DSH_TAURI_UPDATE_CHECK` | 启动时挂更新检查的钩子 |
| `DSH_TEST_CTRL_C=1` | opt-in 跑 Ctrl+C 组投递测试（见 08） |
| `DSH_NO_TELEMETRY=1` | verify 冒烟跑 `bin.js --version` 时关掉遥测 |

（脚本侧的 `DOWNLOAD_TEST_ORIGIN/DOWNLOAD_TEST_RELEASE_ID/DOWNLOAD_TEST_COS_*
/DOWNLOAD_PROD_COS_*` 见 05 §4。）

## 2. 注册表

| 键 | 写者 | 含义 |
|---|---|---|
| `HKCU\Software\DeepSeek\DSH Desktop\HarnessRoot` | 安装器 PREINSTALL | 挂载的 harness（detect 脚本 100 分来源） |
| `HKCU\Software\DeepSeek\DSH Desktop\InstallRoot` | 安装器 POSTINSTALL | 外壳安装目录 |
| `HKCU\...\Run\DSH` | autostart 插件 | 开机自启（卸载时清除） |

## 3. 文件路径

| 路径 | 内容 |
|---|---|
| `%TEMP%\dsh-tauri.log` | 外壳事件日志（与 UI 环形缓冲同源） |
| `%TEMP%\dsh-install-error.txt` | 静默安装失败摘要 |
| `%TEMP%\dsh-deploy.log` | deploy-harness.ps1 日志 |
| `$DSH_HOME\task-board\ledger-v2.lock` | 任务板持有者 `{"pid","token","startedAt","probe"}` |
| `<harness>\node\node.exe` / `pnpm.cmd` | 部署脚本随 harness 带的 Node 与 corepack shim（`node_for_checkout`/`pnpm_for` 优先使用） |
| `Resources\cli\lib\bin.js`、`Resources\node\node.exe` | 自带运行时包的随包资源（setup 里 set_bundled_*） |

## 4. tauri.conf.json 关键字段

- `version`：**版本单一来源**（0.1.22）；identifier `ai.deepseek.dsh.desktop.tauri`。
- `build.frontendDist = ../dist`：只有 splash 页。
- `app.withGlobalTauri = true`：splash HTML 直接用 `window.__TAURI__`。
- `bundle.targets = ["nsis"]`、`nsis.installMode = currentUser`（免管理员）、
  中英双语、`installerHooks = installer-hooks.nsh`（生成物）。
- `webviewInstallMode.downloadBootstrapper`：缺 WebView2 时安装器现下载。
- `createUpdaterArtifacts = true` + `plugins.updater.endpoints/pubkey`：见 06。

## 5. capabilities（IPC 面最小化）

- `default.json`（窗口 `splash`）：`core:default` + 4 个壳命令 allow-*。
- `host-page.json`（窗口 `main`，remote urls `http(s)://{127.0.0.1,localhost}:*`）：
  仅 `allow-open-external`。Host 绑其它地址须扩 pattern 表。
