# 05 外围工具与测试

仓库根目录下除两个主工程外的伴生组件：三个小工程（cli / gputemp / SmokeTests）、一个退役残留（WmiProbe）、参考实现（vendor）与若干本地杂物。

## cli/ —— llamadsh-cli 独立控制台客户端

- `cli/llamadsh-cli.csproj`（26 行）+ `cli/Program.cs`（19 行）。
- net8.0 控制台 `Exe`，`AssemblyName=llamadsh-cli`，**不引用 WPF**；通过 `<Compile Include="..\LlamaDSH_Launcher_CS\..." Link="src\...">` 以链接源码方式共享三个文件：`Logging.cs`、`Services/AgentApi.cs`、`Services/AgentCli.cs`。
- `Program.cs` 只做一件事：给 `args` 前面插一个 `"llamadsh-cli.exe"` 伪参数后调 `AgentCli.Run(shifted)` —— 与 GUI 内嵌的 `LlamaDSH_Launcher.exe cli <命令>` 行为一字不差。
- 动机：控制台子系统的 stdout 天然是管道，脚本/agent 直接捕获并可等待；GUI 内嵌入口仍保留。
- 产物链：`一键封包.cmd [4/8]` 单文件 publish → 拷入 `installer_staging/` → `installer.iss` 装进 `{app}`。
- 命令与退出码见 [07-Agent-API与CLI](07-Agent-API与CLI.md)。

## gputemp/ —— GPU 温度探针子进程

- `gputemp/Program.cs`（47 行，顶层语句）+ `gputemp.csproj`（net8.0-windows 控制台）。
- 依赖 `LibreHardwareMonitorLib **0.9.3**`（钉版本：0.9.3 有 netstandard2.0 目标且依赖 System.Management 8.0；0.9.4+ 依赖 SM 9/10，net8 下无法还原）。
- 参数与输出：
  - `--loop`：每 2 秒循环采样不退出；连续 8 秒无输出会被主程序判定为「gpu_temp 数据源不可用」。
  - `--diag`：额外输出全部非温度传感器行。
  - 正常输出：`[HardwareType] SensorName=值:F1` 一行一个值。
- 使用方：仅 Windows 端 `GpuMonitor.TryGpuTempHelper` 以子进程方式调用（避免 LHM 内核驱动直接加载进 UI 进程）；启动前 `ReapStaleGpuTempLoops` 清理上一轮孤儿（强杀/崩溃会留下 `gputemp --loop`，几个并存会锁住 exe 文件）。Linux 端不用它。
- `LlamaDSH_Launcher_CS/gputemp/` 子目录：只放成品 `gputemp.exe`（3.4MB）+ LHM 内核驱动 `gputemp.sys`（14KB），由封包脚本从本工程 publish 目录拷来；源码只在根 `gputemp/`。

## tests/SmokeTests/ —— 零 NuGet 冒烟测试

- `tests/SmokeTests/Program.cs`（524 行）+ `SmokeTests.csproj`。
- 设计：**不引用 WPF 主工程、不引入任何 NuGet 包**，直接 `<Compile Include>` 链接 8 个被测源码文件（ProcessRunner、Logging、AuthenticodeVerifier、AgentApi、AgentCli、DshIdentity、ProcLiveness、BackendChoice），只依赖 BCL，可离线跑。
- 自制 `Check()` 断言框架，输出 PASS/FAIL，**进程退出码 = 失败数**。

| 测试 | 覆盖 |
|---|---|
| TestBasicRun / TestExitCode / TestStderrSeparation / TestSpacesInArguments / TestMissingExecutable / TestTimeout / TestLargeOutput | ProcessRunner：基本执行、退出码、双流分离、含空格参数、缺 exe、超时强杀不挂死、大输出不截断 |
| TestLogRotation / TestDiagnostics | AppLog：写入/4MiB 轮转/脱敏/逐行时间戳/诊断文本 |
| TestAuthenticode | AuthenticodeVerifier 真实验签 |
| TestAgentCliParse | cli 命令→HTTP 映射（status/llama stop/breaker set/api 逃生舱/未知命令） |
| TestAgentApiHttp | 真 HTTP 往返：起 AgentApi（随机端口 + `LLAMADSH_AGENT_PORT/TOKEN` 环境变量），验证 agent.json 落盘与 GET/POST 处理 |
| TestDshIdentityJudge | 三层身份决策表（命令行可读/不可读 × HTTP 指纹） |
| TestBackendChoice | 后端选择与预编译资产 token 匹配链（真实资产名 `llama-b12212-bin-win-*`） |
| TestProcLiveness | 进程对象脱钩后判活、PID 复用防护、Dispose 不抛 |

跑法：`dotnet run --project tests/SmokeTests/SmokeTests.csproj`。注意与封包脚本 `[6/8]` 跑的 `selftest.ps1`（安装/血统回归）是**两套独立测试**；Linux 侧对应 `selftest.py`。

## 依赖关系小结

```
主工程 LlamaDSH_Launcher.csproj
 ├─ 共享源码 ──→ cli/llamadsh-cli.csproj（Logging + AgentApi + AgentCli）
 ├─ Content 拷贝 ──→ gputemp 成品（源码在根 gputemp/，独立编译）
 └─ 链接编译被测源码 ──→ tests/SmokeTests（零 NuGet）

一键封包.cmd：publish gputemp → publish cli → publish 主程序
           → staging → selftest.ps1 → ISCC(installer.iss) → [签名] → Linux zip

vendor/、WmiProbe/：不参与任何编译与打包。
```
