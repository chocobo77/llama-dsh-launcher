# 06 构建打包与发布

## 环境要求

- **Windows 端源码跑**：.NET 8 SDK（构建）/ .NET 8 Desktop Runtime（运行）；Win10/11 x64。
- **运行发布版**：自带发布产物不含运行时时需 .NET 8 Desktop Runtime（安装器会检测并自动装，见下）。
- **打包**：dotnet CLI + Inno Setup 6（7 兜底）。
- **目标工具链**：llama.cpp 目录（含 llama-server.exe）、DSH 源码目录（含 apps/cli）、Node 24 + pnpm（可程序内一键装）。
- **Linux 端**：Python 3.10+、pyyaml（必需）；python3-gi + gir1.2-webkit2-4.1（窗口）、python3-dbus（托盘）可选。

## 日常构建命令

```bash
# Windows 主程序
dotnet build LlamaDSH_Launcher_CS/LlamaDSH_Launcher.csproj

# 冒烟测试（零 NuGet，退出码=失败数）
dotnet run --project tests/SmokeTests/SmokeTests.csproj

# 独立 cli 工具
dotnet publish cli/llamadsh-cli.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true

# Windows 安装/血统回归（PowerShell 5.1，文件必须保持 UTF-8 BOM）
powershell -File LlamaDSH_Launcher_CS/selftest.ps1

# Linux 全量自检（385 处 check 断言）
python3 LlamaDSH_Launcher_Linux/selftest.py

# Linux 端打包
bash LlamaDSH_Launcher_Linux/build_release.sh   # → dist/LlamaDSH_Launcher_Linux_v<VER>.tar.gz

# Linux 端运行
python3 LlamaDSH_Launcher_Linux/main.py [-p 端口]
bash LlamaDSH_Launcher_Linux/start.sh           # 托盘模式优先，逐级降级
```

## 一键封包.cmd（Windows 发布主流程）

用法：`一键封包.cmd [版本号] [-nopause]`（如 `一键封包.cmd 1.2.0 -nopause`）。8 步编号流程，每步向 `pack_run.log` 追加带时间戳记录：

| 步骤 | 内容 |
|---|---|
| [1/8] | 可选版本参数：正则校验 x.y.z，同步写 `installer.iss MyAppVersion` 与 csproj `Version/AssemblyVersion/FileVersion`（保留 BOM/CRLF） |
| [2/8] | 环境检查：dotnet CLI；ISCC 自动定位（注册表 → 常见路径兜底） |
| [3/8] | `taskkill` 结束运行中的 LlamaDSH_Launcher.exe 并轮询等进程消失（最多 20 次），防发布目录占用 |
| [4/8] | `dotnet publish` 三连（均单文件、非自包含）：gputemp（成品拷到 `LlamaDSH_Launcher_CS/gputemp/gputemp.exe`）→ llamadsh-cli → 主程序 |
| [5/8] | 清空重建 `installer_staging/`：主程序 exe + gputemp.exe + llamadsh-cli.exe + app.ico；主程序 <512KB 判失败 |
| [6/8] | 跑 `selftest.ps1`（输出 `installer_output/selftest.log`）：FAIL 行计数——**计数为 0 说明测试进程崩了，不能报成「0 项未通过」**；非 0 退出码或无日志均中止 |
| [6.5] | 可选代码签名：存在 `signtool-config.inc`（不入库，模板 `.example`）才执行；签名后 `Get-AuthenticodeSignature` 复核，失败中止——绝不产出「以为签了其实没签」的包 |
| [7/8] | ISCC 编译 → `installer_output/LlamaDSH_Launcher_Setup.exe`（先删上一轮 Setup.exe 防旧包冒充；<1MB 判失败；完整输出写 `iscc_build.log`） |
| [8/8] | 打 Linux 源码 zip：robocopy 排除缓存/截图/`.git`/`dist` → 先压临时名成功才改名 `LlamaDSH_Launcher_Linux_<版本>.zip`（杀软冲突自动重试一次） |

收尾：`installer_output/` 只留 Setup.exe 与 Linux zip；`certutil` 算 SHA256。失败路径会提醒「目录里的旧 Setup.exe 时间戳是上一轮的，不要发布」。

## installer.iss（Inno Setup 6，700 行）

- **双安装模式**：`PrivilegesRequired=lowest` + `PrivilegesRequiredOverridesAllowed=dialog commandline`。「仅为自己安装」= 用户级（HKCU，默认 `%LocalAppData%\Programs`）；「为所有用户安装」= 提权重启装 Program Files（**优先 `D:\Program Files\LlamaDSH_Launcher`**——模型权重与 DSH 依赖都在 D 盘，只拦无 D 盘/非固定盘）。命令行覆盖：`Setup.exe /CURRENTUSER` / `/ALLUSERS`。
- **.NET 8 前提**：`PrepareToInstall` 检测 `dotnet --list-runtimes`（目录回退）；缺失时自动下载安装（curl → URLDownloadToFile 回退），**SHA-256 硬编码基线 + 签名主体 Microsoft Corporation 双门**。静默模式缺 .NET 直接明确失败不自动装——「仅为自己安装」只有本机已有运行时才真的不需要管理员（文案已写明）。
- **跨安装方式检测**：`PrepareToInstall` 查对面 hive 的卸载键，重复安装提醒（静默下不弹窗只写日志）。
- **血统问题的程序侧防线**：`[Run]` 的 `runasoriginaluser` 挡不住 `__COMPAT_LAYER` 血统（实测），真正的保险是 `App.xaml.cs` 白名单 + 一次封顶自重启。
- **写哪些东西**：三个 exe 到 `{app}`、`app.ico` 到 `{app}\Resources`、开始菜单/桌面快捷方式、卸载注册表键（HKCU 或 HKLM）；无服务、无文件关联、无 PATH 修改。`CurStepChanged(ssPostInstall)` 写 `install-scope.txt`（scope/dir/installedAt，纯 ASCII）供 `InstallScope` 判定。
- **AppId** `{A7F8B3C4-…}`：iss、[Code] UNINST_SUBKEY、`InstallScope.UninstallSubKey` 三处必须一致（selftest §C 静态断言）。
- `AppMutex=LlamaDSH_Launcher_SingleInstance_Mutex` 与主程序单实例 mutex 同名（安装时会等/关运行中的实例）。

## 代码签名

- 配置模板 `signtool-config.inc.example`：复制为 `signtool-config.inc`（gitignore），三选一——A) CA 签发 PFX（密码走环境变量 `PFX_PASSWORD`，不写入文件）；B) Azure Trusted Signing；C) 证书存储指纹。`%SETUPFILE%` 占位符由封包脚本替换为 Setup.exe 路径。
- 无配置时跳过签名（不中止）；自签名证书无分发价值（模板注释警示）。

## 版本同步规则

版本真源是 `installer.iss` 的 `MyAppVersion`。改版本要么走 `一键封包.cmd <版本>`（自动同步四处），要么手动同步：iss `MyAppVersion` ↔ csproj `Version/AssemblyVersion/FileVersion`。漏同步的症状：exe 属性与 `cli status` 报的版本停在旧值。

## 测试体系总览

| 测试 | 位置 | 跑法 | 覆盖 |
|---|---|---|---|
| 冒烟测试 | `tests/SmokeTests/` | `dotnet run --project …`（退出码=失败数） | ProcessRunner/AppLog/验签/AgentApi/AgentCli/DshIdentity/BackendChoice/ProcLiveness |
| 安装回归 | `LlamaDSH_Launcher_CS/selftest.ps1` | 封包 [6/8] 自动跑 | InstallScope 三级判定、LineageGuard 决策表、AppId/GUID 一致性等静态不变量（「已修缺陷不得复活」断言） |
| Linux 自检 | `LlamaDSH_Launcher_Linux/selftest.py` | `python3 selftest.py`（385 处 check 断言） | 两端全功能行为级 + 协议级 + 历轮 bug 回归 |
| 血统 shim | `selftest_lineage_shim.py` | Windows 上跑 selftest §31/§32 | 伪造 fcntl/pwd 切片执行 |

selftest.ps1 的兼容性事实：必须保持 **UTF-8 with BOM**（PowerShell 5.1 无 BOM 按 ANSI 读）；5.1 的 `Start-Process -ArgumentList` 拒绝空串元素（用 `<none>` 占位）。
