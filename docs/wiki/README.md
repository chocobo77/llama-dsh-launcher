# DSH Desktop (Tauri) Code Wiki

本目录是 `dsh-desktop-tauri` 项目的结构化代码维基（Code Wiki），基于对仓库全部
78 个受版本控制文件的逐行通读写成。内容覆盖：整体架构、模块职责、关键类与函数、
依赖关系、构建/运行/更新方式，并附与 `D:\code\启动器` 仓库 subtree 融合的核对报告。

> 权威事实来源始终是代码与 `README.zh.md`（项目自身的中文手册）。本 Wiki 是对它们的
> 函数级展开与交叉索引；若两者冲突，以代码为准并欢迎修正本 Wiki。
